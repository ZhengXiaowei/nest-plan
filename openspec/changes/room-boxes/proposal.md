## Why

上传户型图后要描墙、放门窗、圈房间、标定比例才能开始设计，第一次用的人不知道从哪下手；AI 识别墙体又不够准，校对起来比自己描还累。用户要的是「小白一下子就知道怎么玩」，操作越少越好，但拆墙时还得知道哪面是承重墙。

## What Changes

- 户型还原默认改成「框房间」流程，四步，每步只做一件事：
  1. 框房间：在图上拖出每个房间的方框，或者双击房间里面自动框；方框边会吸到图上的墙线和旁边方框的边。框好点名字（客厅、主卧……一点就选）。连了模型时可以「AI 帮我框」。
  2. 门窗和承重墙：墙按方框自动生成（外圈是外墙，房间之间是隔墙）。系统按图上的样子先猜好：粗黑实心的墙标成承重墙，墙上的缺口猜成门，外墙上的细线段猜成窗，外墙缺口猜成入户门；猜的用虚线显示。选「门 / 推拉门 / 窗 / 入户门 / 承重墙」，点墙放上，再点一下去掉。
  3. 定尺寸：填套内面积，按方框总面积算比例；也可以点一面墙填它的长度。填完方框上直接显示每个房间的长宽，一眼能看出对不对。AI 读到图上尺寸标注时自动填好。
  4. 开始设计。
- 原来的描墙工具留作「精修」：框房间的结果一键转成精修草稿继续改。
- 按图猜的墙类型带「待核实」标记进入设计页：拆「待核实」的墙时提示先找物业核实；属性面板可以一键确认或改成承重墙。

不做：CAD / PDF 导入；斜墙和不规则房间（不规则房间用几个方框拼，或去精修里画）；多层户型；同名相邻方框合并成一个房间。

## Capabilities

### New Capabilities
- `room-boxes`: 框房间的户型还原流程：方框绘制与吸附、自动框、由方框生成墙、按图猜承重墙和门窗、面积定比例、生成户型。

### Modified Capabilities
（无）

## Impact

- 新增 `src/features/trace/boxes.ts`（方框 → 墙、门窗挂墙、生成草稿，纯函数）、`src/features/trace/imageScan.ts`（图像分析：墙厚估计、边吸附、自动框、猜承重墙和门窗，纯函数，输入是灰度数组）及测试。
- `traceStore.ts` 加框房间的状态和步骤；`TracePage.tsx` 默认显示框房间流程，新增 `BoxCanvas.tsx`。
- `model/types.ts` 的 `Wall` 加可选 `unverified`；设计页拆墙提示和属性面板相应调整。
- 还原页本来就是按需加载，首屏体积不变；不加依赖。
