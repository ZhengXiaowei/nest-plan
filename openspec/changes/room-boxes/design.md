## 方案

### 数据
- 框房间状态独立于描墙草稿：`boxes`（像素矩形 + 名字）、`marks`（门窗：类型 + 图上位置点，猜的带 `guessed`）、`wallMarks`（墙类型：位置点 + 承重 / 非承重，用户点的或猜的）。
- 墙每次由方框现算（`wallsFromBoxes`），不存。门窗和墙类型按「位置点」挂到现算出的墙上，所以拖方框后门窗和标记还在原处。

### 由方框生成墙
- 把所有方框边按所在直线分组（横线按 y、竖线按 x），每条线上用所有边的端点切成小段；每小段看两侧各被哪个方框盖住，一侧空着是外墙，两侧都有是隔墙；两侧房间相同的相邻小段合并成一段墙。
- 房间轮廓 = 方框每条边向内缩该边上墙厚的一半（外墙、承重 240 mm，隔墙 120 mm），面积算法和生成户型用同一个。

### 图像分析（`imageScan.ts`，输入灰度数组）
- 暗像素：灰度 < 110。
- 墙厚参考：沿行、列统计暗像素连续段长度，取 ≥ 4 px 的段里按长度加权最常见的那个（实心墙产生大量同样长的段）。
- 边吸附：在边附近 ±2.5 倍墙厚内找暗像素比例最高的一条带，吸到带中心。
- 自动框：从双击点向外填充非暗像素，到图边界就放弃（点在外面）；对填充区算距离，去掉离边界小于 2 倍墙厚的部分（截断门洞），取包含双击点的那块，外扩回 2 倍墙厚，再把四条边吸到墙线中心。
- 猜墙：每段墙沿长度采样，每个采样点在垂直方向 ±1.5 倍墙厚内找跨过中心线的最长暗段长度。中位数 ≥ 外墙中位数的 0.75 → 承重；连续为 0 的段长 2.2～6 倍墙厚 → 门（外墙 → 入户门，只取一个），更长 → 推拉门；外墙上细于 0.45 倍墙厚但不为 0 的连续段 ≥ 2 倍墙厚 → 窗。

### 比例
- 面积：比例 s 使 Σ(方框内缩后的面积) = 套内面积；内缩量和 s 有关，迭代 3 次收敛。
- 尺寸标注（AI 读到）或量一面墙填长度时直接用。

### 交互
- 第 2 步画布只有一种操作：拖空白处画框，拖框移动，拖边调整，双击自动框；按住空格或右键拖动平移，滚轮缩放。
- 第 3 步顶部五个笔刷，点墙即生效，再点去掉。
- 步骤条可以点回前面的步骤；进入第 3 步时（方框改过才）重新猜一次，只替换猜的，用户点过的保留。
