# 栖图 NestPlan

上传户型图，还原成可编辑的户型，在线做 2D 布置和 3D 预览，最后用一段「改造回放」动画看毛坯一步步变成你的家。

纯前端应用，数据保存在你自己的浏览器里。AI 功能使用你自己填写的模型接口和密钥，不经过任何栖图服务器。

## 现在能做什么

- **户型还原**：上传户型截图，手动描墙、放门窗、圈房间，或者让你连接的多模态模型先识别一遍再逐项校对；在图上点两下标定一段已知长度，一键生成可编辑户型。
- **设计**：从家具库点一下或直接拖到平面图上；拖动摆放时靠近墙面自动贴上，拖右下角改尺寸，属性面板里精确改宽深、位置、角度、颜色，复制、调整上下层级；测量、拆非承重墙（承重墙和外墙拆不了）、砌新墙；点房间改名、换地面材质、改单价，按面积估算地面造价；撤销 / 重做，方案自动保存在本机。
- **平面图**：外圈两道尺寸标注，图层开关（尺寸、房间名、家具、网格、突出承重墙），放大缩小和 1:60 / 1:100 比例，触屏双指缩放。导出平面图图片，导出 / 导入方案文件（也能读原版 floorplan-3d 导出的布置），重置为示例方案。快捷键：V / M / X / B 切工具，R 旋转，方向键微调，⌘D 复制，T 切平面和 3D，F 适应窗口，Shift F 全屏。
- **3D 和漫游**：带软阴影和环境光的 3D 视图，点家具就能选中；斜视、俯视一键切换，点房间列表飞过去；剖切墙（墙只显示到 1.2 米），夜景开灯，日照时间从早 7 点调到晚 6 点，家具和房间名可以隐藏。切到「漫游」用 WASD 或触屏摇杆第一视角走进屋里，门能开关，墙和家具都挡人。
- **改造回放**：自动生成一段动画：交房毛坯 → 拆墙 → 砌墙 → 铺地刷墙 → 家具进场 → 第一视角按房间走一遍。可以拖进度、按章节跳转，也能导出 720p / 1080p 视频（逐帧渲染，带章节字幕）。
- **AI 助手（第一版）**：带着当前户型的房间和家具信息问布局、动线、预算问题。
- **连接 AI**：支持 OpenAI 兼容接口和 Anthropic 接口，地址、密钥、模型都由你填写，默认只保存在当前会话。用 DeepSeek 时可以开关深度思考（默认关），户型识别更快，也不会把输出额度用完；识图要用 `deepseek-flash`。

## 接下来

路线图和性能、动效指标见 [docs/plan.md](docs/plan.md)。主要是：PDF 户型图导入、AI 助手直接改方案，之后再做 DXF（CAD）导入。

## 本地开发

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev        # 本地开发
npm run build      # 类型检查 + 生产构建
npm run budget     # 构建后报告首屏体积（gzip），CI 里会和上一次对比
npm run theme      # 改了 src/theme/blueprint.ts 之后重新生成主题
```

## 技术栈

- Vite + React 19 + TypeScript
- [Astryx](https://github.com/facebook/astryx)（基于 StyleX 的组件库），自定义「蓝图」主题：白底 + 群青蓝 #2747D6
- 2D 平面图：SVG，单位毫米，按图层拆分避免拖动时整图重绘
- 3D：three.js + @react-three/fiber + drei，按需渲染，单独拆包、不进首屏
- 状态：zustand（含撤销栈），本地存储：IndexedDB

## 目录结构

```
src/
  model/        户型数据模型、几何计算、材质、家具库、示例户型
  store/        方案状态与撤销 / 重做、本地保存
  features/
    plan2d/     SVG 平面图画布
    view3d/     3D 视图
    design/     设计页（家具库、属性、房间预算、AI 助手）
    trace/      户型还原页
    ai/         AI 接口设置、请求客户端、户型识别
    replay/     改造回放（时间线、漫游路线、视频导出）
  theme/        Astryx 主题源文件与生成产物
```

## 参考来源与致谢
